# Customer Shopping Behavior Analysis

## Project Overview
This project analyzes customer shopping behavior to uncover purchasing patterns, customer preferences, and key business insights. The goal is to help businesses make data-driven decisions using analytics and visualization.

## Business Problem
Businesses need to understand customer purchasing patterns, product preferences, and subscription behavior to improve sales and customer engagement.

## Tools & Technologies
- SQL
- PostgreSQL
- Python
- Pandas
- Power BI
- Microsoft Excel

## Project Workflow

### 1. Data Cleaning
- Removed inconsistencies
- Checked missing values
- Standardized data formats

### 2. Exploratory Data Analysis
- Customer demographics analysis
- Purchasing trend analysis
- Product category analysis

### 3. SQL Analysis
- Customer segmentation
- Sales performance analysis
- Subscription impact analysis

### 4. Dashboard Development
Created interactive Power BI dashboards displaying:
- Total Sales
- Average Order Value
- Customer Demographics
- Category Performance
